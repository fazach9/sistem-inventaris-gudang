# 📦 Sistem Informasi Inventaris Gudang (Web-Based)

Repositori ini berisi kode sumber aplikasi **Website Inventaris Gudang** yang dikembangkan sebagai bagian dari proyek Praktik Kerja Lapangan (PKL). Aplikasi ini dirancang untuk mendigitalisasi proses pencatatan, pelacakan, dan pemantauan ketersediaan stok barang gudang secara akurat dan terstruktur.

---

## 🎯 Fitur Utama

* **Manajemen Data Barang (CRUD):** Tambah, lihat, ubah, dan hapus data stok barang dengan cepat dan mudah.
* **Pencarian & Filter Cepat:** Integrasi **DataTables** untuk memudahkan pencarian nama barang, kode item, serta pengurutan data secara instan.
* **Pemantauan Stok Barang:** Memantau jumlah stok masuk, stok keluar, dan ketersediaan barang terkini untuk mencegah selisih data.
* **Antarmuka Responsif:** Tampilan bersih dan ramah pengguna di berbagai ukuran layar (desktop maupun perangkat mobile) menggunakan **Bootstrap**.

---

## 🛠️ Teknologi yang Digunakan (Tech Stack)

* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, Bootstrap
* **Library Pendukung:** DataTables (jQuery)

---

## ⚙️ Cara Menjalankan Proyek Secara Lokal

1. **Clone atau Unduh Repositori:**
   ```bash
   git clone https://github.com
   ```
2. **Pindahkan ke Direktori Server Lokal:**
   Letakkan folder proyek ke dalam direktori `htdocs` (jika menggunakan XAMPP) atau `www` (jika menggunakan Laragon).
3. **Konfigurasi Basis Data:**
   * Buka **phpMyAdmin** melalui browser (`http://localhost/phpmyadmin`).
   * Buat database baru dan impor file `.sql` yang tersedia di dalam folder proyek ini.
   * Sesuaikan pengaturan koneksi database (host, username, password, dan nama database) pada file konfigurasi PHP.
4. **Jalankan Aplikasi:**
   Buka browser dan akses `http://localhost/nama-folder-proyek`.
